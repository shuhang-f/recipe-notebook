A small personal recipe system.

## Goal

Start as a notepad, with just enough structure to make recipes easier to find and use.

## First version

- A recipe title
- Ingredients
- Directions
- Simple search
- Edit and delete

西红柿炖牛肉

西红柿800g
牛肉1000g （个人喜欢买肥一点的Chuck Roast or Shoulder Roast）
盐15g
食用油
葱姜蒜适量
酱油
香叶，八角，花椒

新鲜买的牛肉 直接切块加油，油热了大火下锅
中火煎牛肉块 一直煎到出水 然后水慢慢变少 到锅里剩的都是油
加姜蒜，香叶，八角，花椒进锅里爆香
同时烧一壶水 水量能没过食材多一点
爆香完加切好的西红柿（不用去皮 皮营养很高，切成片就可以）

炒一炒西红柿味道出来即可加水开炖
水开了加葱（给他打结），加15g盐，酱油看自己口味
小火炖上一个小时（有条件1个半）
煮个米饭

这个汤咸度比较适中可以直接喝，肉偏淡但是很油 配米饭很爽
